MUSCU 6 SEMAINES — PWA

Cette appli est une Progressive Web App (PWA), utilisable sur téléphone et hors ligne après installation.

Installation Android / Chrome :
1. Héberger le dossier sur un service HTTPS (GitHub Pages, Netlify, Vercel, etc.).
2. Ouvrir l'adresse sur le téléphone.
3. Menu Chrome > Ajouter à l'écran d'accueil / Installer l'application.

Installation iPhone / Safari :
1. Ouvrir l'adresse HTTPS dans Safari.
2. Partager > Sur l'écran d'accueil.

Données :
Les séances et réglages sont stockés localement dans le navigateur (localStorage). Aucun compte n'est nécessaire.
